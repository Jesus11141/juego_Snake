# Juego de Snake UNIBE

Un juego de Snake desarrollado con Flutter, personalizado para la Universidad Iberoamericana del Ecuador (UNIBE).

## Descripción

Este juego de Snake incluye características especiales como:

- Tres niveles de dificultad (fácil, medio y difícil)
- Frutas buenas y malas
- Modo bonus con estrellas
- Serpientes enemigas en modo difícil
- Controles táctiles intuitivos
- Diseño con los colores institucionales de la UNIBE (azul y rojo)


## Cómo jugar

1. Selecciona un nivel de dificultad
2. Desliza en la pantalla para controlar la dirección de la serpiente
3. Come frutas para crecer y ganar puntos
4. Evita las frutas malas y las serpientes enemigas
5. Recoge estrellas para activar el modo bonus
